# 🚀 Spark Internals & Performance Optimization

> A comprehensive guide to understanding **Apache Spark under the hood**—covering Spark Architecture, Execution Engine, Memory Management, Performance Optimization, and Interview Preparation with practical PySpark examples.

---

## 📖 About This Repository

Most Spark tutorials focus on writing DataFrame APIs or SQL queries. This repository goes one level deeper and explains **how Spark actually executes your code**.

The goal is to understand Spark from a production engineer's perspective by exploring:

* Spark Architecture
* Driver & Executors
* Jobs, Stages & Tasks
* DAG & Lazy Evaluation
* Partitions & Parallelism
* Shuffle Internals
* Spark UI Analysis
* Memory Management
* Caching & Persistence
* Performance Tuning
* Bucketing
* Broadcast Hash Join
* Driver Out Of Memory (OOM)
* Real-world Optimization Techniques
* Interview Questions
